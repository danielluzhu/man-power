      How a journey is timed

      1. 1

        Search for the fastest way

        Not the shortest — the soonest. Every step costs what it costs to cross.

      2. 2

        Let the cost do the deciding

        Swimming is three and a half times slower than running, so a route will go thousands of kilometres out of its way to cross at a strait. Climbing costs time, so it rounds mountains. None of it is a rule.

      3. 3

        Time each leg on its own record

        Each leg is timed against the record for its distance — a river crossing swum at 800 m pace, the four thousand kilometres either side run at marathon pace.

      The pace book

      Applied as pace, not as a flat duration: a 400 m hop takes 400 m at Kerr's mile pace, not his full 3:42.66.

      Three records deliberately left out

      The 2 mile, 10 mile and 30 km bests are each slower in pace terms than their neighbours — a sub-two-hour marathon outpaces the standing 30 km best. Including them would let a longer journey arrive before a shorter one, so they are left off.

      Written down

        Send one yourself

        The calculator times a journey. The app sends one — sealed until the courier could genuinely have arrived.

        1. Enter your number. A six-digit code arrives by text. There is no password.
        2. Pick where you stand. Every journey is measured from there, so it matters.
        3. Write to another courier. Then wait, which is the whole point.
        Sign in

        Your number signs you in and is never shown to anyone else. Turn on arrival alerts — a journey outlasts any browser tab.

        Run the whole thing

        A small Bun server with SQLite behind it.

        # clone and start
git clone https://github.com/danielluzhu/man-power.git
cd man-power && bun install
bun run server.js            # http://localhost:4321

# or install it as a systemd service
sudo deploy/install.sh       # restarts on failure, starts on boot

        You need two couriers for anything to happen — enlist a second in a private window and write to yourself the long way round.
